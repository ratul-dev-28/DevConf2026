DevConf 2026 — Code. Connect. Create.

<h2>📌 About the Project</h2>

DevConf 2026 is a frontend conference website designed as part of my Programming Hero Bootcamp — Batch 14 assignment.

The goal of this project was to transform a provided design concept into a functional, responsive webpage using semantic HTML5 and modern CSS3, while maintaining a clean visual hierarchy and user-friendly experience.

The project includes a conference hero section, speaker profiles, ticket/pricing plans, and an additional custom section created to make the website more engaging.

<h2>🌐 Project Overview</h2>

The website represents a fictional developer conference where developers, engineers, and technology enthusiasts can explore the event, discover speakers, and choose a suitable conference pass.

**Main Sections**
- *Navigation Bar* — Conference branding, navigation links, and registration CTA
- *Hero Section* — Event introduction with a prominent call-to-action
- *Speakers Section* — Featured speakers with their roles and expertise
- *Pricing Section* — Multiple ticket plans for different attendee needs
- *Custom Section* — An additional AI-assisted section related to the conference
- *Footer* — Social links, branding, and copyright information

<h2>🛠️ Tech Stack</h2>
- Technology	Purpose
- HTML5	Semantic structure and content
- CSS3	Styling, layouts, responsiveness, and visual effects
- Penpot	UI design and layout reference
- Git & GitHub	Version control and project management
- GitHub Pages	Deployment


🎯 Learning Outcomes

This project helped me strengthen my understanding of frontend development fundamentals.

**What I Learned**
- How to structure a complete webpage using semantic HTML5
- How to create responsive layouts using CSS Flexbox and Grid
- How to organize CSS for larger webpage sections
- How to work with typography, spacing, colors, and visual hierarchy
- How to create reusable UI patterns such as cards and buttons
- How to make layouts responsive across different screen sizes
- How to work with local images and assets
- How relative file paths work in HTML and CSS
- How to use Git and GitHub for version control
- How to deploy a static website using GitHub Pages
- How AI can be used as a supporting tool during the design and development process

Most importantly, I learned that good frontend development is not only about making a page look attractive — it is also about writing organized, maintainable, and responsive code.
